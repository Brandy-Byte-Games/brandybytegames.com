Brandy Byte Games officially has a website now. We're working towards the first playtest of our first game! This is the start of a new journey, one which we hope will be gratifying. 

There are a few key goals of this upcoming playtest. First is to identify the least fun aspects of the prototype and improve it or remove it. If something works really well, we'll try to lean into it more, otherwise, we'll keep experimenting. Second is to figure out how to better structure future playtests. These playtests will be limited to just family and friends. Finally, we want to get comfortable with the idea of frequent minor playtests to quickly iterate on ideas. With plans for several games down the line, it's going to be crucial to start learning how to utilize this feedback as early as possible if we want to make games that reach people.

Launching this website along with a dev log will hopefully serve as a place to post both learnings and updates on the progress of the current in-development game. Once this first project is announced (it doesn't even have a title yet!), it will be posted here.
